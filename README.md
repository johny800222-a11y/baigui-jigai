# 百鬼祭改錄

華人鬼魅版的收服養成 RPG：在農曆七月鬼門開的夜裡，用「祭改」收服 150 隻台灣與華人民俗中的鬼怪、神祇與妖精。

## 怎麼玩
- 直接打開網頁就能玩（手機、平板、電腦皆可，建議手機橫向）。
- 電腦：方向鍵／WASD 移動，Z／空白 確認，X／Esc 取消、開選單。
- 手機：左半邊螢幕是虛擬搖桿，右邊是 A／B 鍵。
- 選單裡可切換「畫面：2.5D／像素2D」與「配樂：國樂／像素」。

## 在自己的電腦上執行
因為音樂（music-*.mp3）與 3D 引擎（three.min.js）是另外載入的，請用本機伺服器開啟，例如：
```
python3 -m http.server 8000
```
然後瀏覽 http://localhost:8000
